# Vinod Catering & Tent Service Website v2
A responsive HTML/CSS/JavaScript starter styled to match the supplied storyboard.

## Files
- index.html: Home, Services, Query, Contact Us
- styles.css: layout, colors, responsive styling
- script.js: menu, gallery dialog, query preparation
- assets/: image crops taken from the supplied storyboard as temporary visual previews

## Preview
Extract this ZIP and open index.html in a browser. For hosting, upload all files and the assets folder together.

## Before publishing
Replace storyboard preview crops with owner-approved real photos. Confirm WhatsApp number in script.js and add official email to SETTINGS.businessEmail. Query submission currently opens a prepared WhatsApp message (or email draft when email is configured); it does not save enquiries on a server or automatically notify all five phone numbers.

## Use with another AI
Upload the ZIP and say:
"Read all current files first. Continue this exact project, preserving the approved four main pages: Home, Services, Query, Contact Us. Gallery opens only when clicked. Keep only Catering, Tent & Tent Items, DJ Service, and secondary Rajai-Gadde & Bedding. Do not add pages/features/services without asking. Return complete updated source files."
